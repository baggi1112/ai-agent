# ai-agent Пользователь пишет боту в ВК. Сообщение через Callback API попадает на сервер.
Нейросеть или ключевые слова определяют суть вопроса (интент).
Бот ищет ответ в базе знаний — таблицах с нормами веса, графиками стрижек и прививок той пуделя. Затем он формирует текст со списками и картинками, который отправляется пользователю обратно в чат. Состояние диалога сохраняется для понимания контекста.
